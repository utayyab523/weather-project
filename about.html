About Our Weather App

Our Mission

Our Weather App provides simple, fast, and real-time weather forecasts for any city across the globe. We aim to help you plan your day with accurate meteorological updates.

Key Features

  • Instant Search: Quick access to current weather conditions worldwide.
  • Detailed Metrics: Live temperature, feels-like, humidity, wind, pressure, and UV index.
  • Responsive UI: Seamlessly optimized for both mobile and desktop screens.

Built With

Developed using modern core web technologies: HTML5, CSS3, JavaScript (ES6+), and integrated with live REST APIs.
